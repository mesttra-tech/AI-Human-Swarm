# Daily Cyber Patch - 2026-06-28

Mode: Public defensive guidance. No private environment data included.

## Executive Summary

- The live CISA Known Exploited Vulnerabilities (KEV) feed remains at catalog version 2026.06.25. Cisco Unified Communications Manager CVE-2026-20230 and PTC Windchill/FlexPLM CVE-2026-12569 are due today, 2026-06-28; Cisco Catalyst SD-WAN Manager CVE-2026-20262 is due tomorrow.
- Recent npm, PyPI, and GitHub Actions incidents show that install hooks, native-build metadata, Python startup hooks, mutable action tags, runners, and OIDC publishing are one credential boundary. Valid provenance confirms origin, not that the originating workflow was safe.
- Treat AI-assisted workflows, MCP servers, agent rules, editor extensions, workspace settings, and tool output as privileged inputs. Keep unfamiliar workspaces restricted, narrowly authorize tools, isolate release jobs, and require human approval for mutations.

```bash
# Set this to your local workspace before running checks.
```

```bash

```

```bash
# Find package manifests, lockfiles, registry configs, native-build metadata, and Python startup hooks.
find "$WORKSPACE_ROOT" -type f \( \
  -name package.json -o \
  -name package-lock.json -o \
  -name npm-shrinkwrap.json -o \
  -name pnpm-lock.yaml -o \
  -name yarn.lock -o \
  -name requirements.txt -o \
  -name pyproject.toml -o \
  -name pylock.toml -o \
  -name uv.lock -o \
  -name binding.gyp -o \
  -name '*.pth' -o \
  -name .npmrc -o \
  -name .pypirc \
\) -not -path '*/node_modules/*' -not -path '*/.venv/*' -print
```

```bash
# Review Node package lifecycle scripts without executing them.
rg -n '"(preinstall|install|postinstall|prepare)"[[:space:]]*:' \
  -g 'package.json' \
  -g '!**/node_modules/**' \
```

```bash

rg --files-with-matches --hidden -i '(_authToken|NPM_TOKEN|NODE_AUTH_TOKEN|PYPI_TOKEN|TWINE_PASSWORD|npm_[A-Za-z0-9]{20,}|pypi-[A-Za-z0-9]{20,})' \
```

```bash
# Review workflows for compromised actions, risky triggers, broad permissions, OIDC minting, and untrusted event context.
rg -n '(codfish/semantic-release-action|simonecorsi/mawesome|pull_request_target|workflow_run|issue_comment|repository_dispatch|allow-unsafe-pr-checkout|id-token:[[:space:]]*write|permissions:[[:space:]]*write-all|secrets:[[:space:]]*inherit|github\.event\..*(title|body|head_ref|ref|label|message|name))' \
```

```bash
# Node incident-triage mode when install-time compromise is suspected.
npm ci --ignore-scripts

```

```bash
# CI/CD and publishing hardening checklist.
# - Remove reported compromised actions before re-running affected workflows.
# - Pin third-party actions to reviewed full commit SHAs or immutable releases.
# - Do not fetch or execute untrusted pull-request code in privileged event workflows.
# - Restrict GITHUB_TOKEN with job-level permissions.
# - Grant id-token: write only to the publish/deploy job that must mint OIDC tokens.
# - Bind OIDC trust to repository IDs, workflow file, ref, environment, audience, and subject claims where supported.
# - Put package publishing behind a dedicated workflow and protected environment.
# - Use ephemeral or freshly rebuilt runners for privileged release jobs.
true
```

```bash
# Package and incident-response hardening checklist.
# - Isolate suspected systems before credential rotation or destructive cleanup.
# - Rebuild affected runners and developer environments from clean images.
# - Rotate affected credentials through approved account UIs if exposure is plausible.
# - Pin reviewed clean versions and regenerate lockfiles from a trusted system.
# - Compare registry artifacts with source tags, attestations, expected publishers, and expected workflow identities.
# - Review native-build metadata and Python startup hooks, not only package lifecycle scripts.
# - Remove stale maintainer and automation accounts and review trusted-publisher bindings during offboarding.
true
```

```bash
# Agent, MCP, editor, and extension hardening checklist.
# - Open unfamiliar repositories in restricted or untrusted mode first.
# - Treat MCP manifests, tool descriptions, extension recommendations, workspace settings, tasks, devcontainers, and agent rules as code.
# - Require explicit authorization and human approval for tools that mutate files, publish packages, call cloud APIs, or trigger CI/CD.
# - Separate read-only discovery tools from write-capable tools and keep credentials outside agent-visible workspaces.
# - Bind MCP tokens to the intended server, forbid token passthrough, minimize scopes, and sandbox local servers.
# - Validate tool output before it becomes another tool's input.
# - Confirm AI review with deterministic scanners, provenance checks, sandboxing, and human review.
true
```
