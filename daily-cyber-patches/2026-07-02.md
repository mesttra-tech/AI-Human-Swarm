# Daily Cyber Patch - 2026-07-02

Mode: Public defensive guidance. No private environment data included.

## Executive Summary

- CISA added Microsoft SharePoint Server CVE-2026-45659 to the Known Exploited Vulnerabilities catalog on 2026-07-01 with a 2026-07-04 remediation deadline. Inventory on-premises SharePoint, apply the Microsoft update or vendor mitigation, reduce exposure, and preserve evidence if compromise is suspected.
- SimpleHelp CVE-2026-48558 reaches its KEV deadline today. Systems that use SimpleHelp should confirm fixed versions and review authentication and technician activity; organizations that do not use it should record non-applicability.
- Developer and AI tooling remain one connected attack surface. Package lifecycle hooks, startup hooks, build metadata, workflow caches, OIDC tokens, runners, editor extensions, MCP tools, agent skills, and persistent memory can bridge untrusted input into privileged execution.
- New GitHub platform changes reinforce two immediate controls: monitor for secrets exposed outside repositories the enterprise owns, and prepare cloud trust policies for immutable Actions OIDC subject claims before the 2026-07-15 default change for new or renamed repositories.

## Copy/Paste Assessment

Run only the checks that match an environment you are authorized to review. These commands list filenames, package references, workflow settings, or executable names; they are not intended to print secret values.

```bash
# Set this to the workspace you are authorized to review.
export WORKSPACE_ROOT="<WORKSPACE_ROOT>"
cd "$WORKSPACE_ROOT"
```

```bash
# Pull current CISA KEV data for defensive patch prioritization.
curl -fsSL https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json -o kev.json
jq -r '.catalogVersion, .dateReleased, (.vulnerabilities | sort_by(.dateAdded) | reverse | .[0:20][] | [.dateAdded,.dueDate,.cveID,.vendorProject,.product] | @tsv)' kev.json
```

```bash
# Find manifests, lockfiles, registry configs, native-build metadata, and Python startup hooks.
find "$WORKSPACE_ROOT" -type f \( \
  -name package.json -o -name package-lock.json -o -name npm-shrinkwrap.json -o \
  -name pnpm-lock.yaml -o -name yarn.lock -o -name requirements.txt -o \
  -name pyproject.toml -o -name pylock.toml -o -name uv.lock -o \
  -name binding.gyp -o -name extconf.rb -o -name '*.pth' -o \
  -name .npmrc -o -name .pypirc \
\) -not -path '*/node_modules/*' -not -path '*/.venv/*' -print
```

```bash
# Review declared Node lifecycle scripts without executing them.
rg -n '"(preinstall|install|postinstall|prepare)"[[:space:]]*:' \
  -g 'package.json' -g '!**/node_modules/**' "$WORKSPACE_ROOT" || true
```

```bash
# Identify files that appear to contain registry credentials without printing file contents.
rg --files-with-matches --hidden -i '(_authToken|NPM_TOKEN|NODE_AUTH_TOKEN|PYPI_TOKEN|TWINE_PASSWORD)' \
  -g '.npmrc' -g '.pypirc' -g 'package.json' -g 'pyproject.toml' \
  -g '.github/workflows/*.yml' -g '.github/workflows/*.yaml' \
  -g '!**/.git/**' -g '!**/node_modules/**' "$WORKSPACE_ROOT" || true
```

```bash
# Review workflow trust boundaries, caches, permissions, OIDC minting, and untrusted event context.
rg -n '(pull_request_target|workflow_run|issue_comment|repository_dispatch|actions/cache|id-token:[[:space:]]*write|permissions:[[:space:]]*write-all|secrets:[[:space:]]*inherit|github\.event\..*(title|body|head_ref|ref|label|message|name))' \
  -g '.github/workflows/*.yml' -g '.github/workflows/*.yaml' "$WORKSPACE_ROOT" || true
```

```bash
# Find third-party actions that are not pinned to a full 40-character commit SHA.
rg -n 'uses:[[:space:]]*[^[:space:]]+/[^[:space:]@]+@[^#[:space:]]+' \
  -g '.github/workflows/*.yml' -g '.github/workflows/*.yaml' "$WORKSPACE_ROOT" \
  | rg -v '@[0-9a-f]{40}([[:space:]#]|$)' || true
```

```bash
# Surface agent, MCP, editor, extension, task, hook, memory, and devcontainer configuration for review.
find "$WORKSPACE_ROOT" -type f \( \
  -name 'mcp.json' -o -name 'mcp.yaml' -o -name 'mcp.toml' -o \
  -name 'AGENTS.md' -o -path '*/.claude/settings.json' -o \
  -path '*/.vscode/extensions.json' -o -path '*/.vscode/settings.json' -o \
  -path '*/.vscode/tasks.json' -o -path '*/.cursor/rules/*' -o \
  -path '*/.github/copilot-instructions.md' -o -name 'devcontainer.json' \
\) -print
```

```bash
# After a suspicious install, import, extension activation, or agent run, list long-running interpreters by executable name only.
ps -axo pid,ppid,etime,comm | rg '(node|bun|python|python3|java|ruby|sh|bash)$' || true
```
