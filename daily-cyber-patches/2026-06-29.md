# Daily Cyber Patch - 2026-06-29

Mode: Public defensive guidance. No private environment data included.

## Executive Summary

- The live CISA Known Exploited Vulnerabilities (KEV) feed remains at catalog version 2026.06.25. Cisco Catalyst SD-WAN Manager CVE-2026-20262 is due today; Cisco Unified CM CVE-2026-20230 and PTC Windchill/FlexPLM CVE-2026-12569 are now overdue.
- Current npm and PyPI campaigns show that install hooks, native-build metadata, Python startup hooks, mutable CI actions, and editor or agent configuration can all become credential-exposure paths. A clean current release or valid provenance does not clear an already pinned or workflow-originated malicious artifact.
- Apply least privilege across the whole developer control plane: protect package publishers, restrict workflow actors and events, bind OIDC trust to immutable repository identity, limit extension marketplaces, keep unfamiliar workspaces restricted, and require approval for agent or MCP mutations.

Run only the checks that match your environment. These commands should not print secret values.

```bash
# Set this to your local workspace before running checks.
export WORKSPACE_ROOT="<WORKSPACE_ROOT>"
cd "$WORKSPACE_ROOT"
```

```bash
# Pull current CISA KEV data for patch prioritization.
curl -fsSL https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json -o kev.json
jq -r '.catalogVersion, .dateReleased, (.vulnerabilities | sort_by(.dateAdded) | reverse | .[] | select(.dateAdded >= "2026-06-01") | [.dateAdded,.dueDate,.cveID,.vendorProject,.product,.knownRansomwareCampaignUse] | @tsv)' kev.json
```

```bash
# Find package manifests, lockfiles, registry configs, native-build metadata, and Python startup hooks.
find "$WORKSPACE_ROOT" -type f \( \
  -name package.json -o -name package-lock.json -o -name npm-shrinkwrap.json -o \
  -name pnpm-lock.yaml -o -name yarn.lock -o -name requirements.txt -o \
  -name pyproject.toml -o -name pylock.toml -o -name uv.lock -o \
  -name binding.gyp -o -name extconf.rb -o -name '*.pth' -o \
  -name .npmrc -o -name .pypirc \
\) -not -path '*/node_modules/*' -not -path '*/.venv/*' -print
```

```bash
# Review declared Node package lifecycle scripts without executing them.
rg -n '"(preinstall|install|postinstall|prepare)"[[:space:]]*:' \
  -g 'package.json' -g '!**/node_modules/**' "$WORKSPACE_ROOT" || true
```

```bash
# Search manifests and lockfiles for package families named in current public reporting.
rg --files-with-matches -i '(@redhat-cloud-services/|easy-day-js|@mastra/|leo-logger|leo-sdk|leo-aws|leo-config|leo-streams|serverless-leo|@vapi-ai/server-sdk|ai-sdk-ollama|autotel|awaitly|ensmallen|embiggen|gpsea|pantheon-agents|pantheon-toolsets)' \
  -g 'package.json' -g 'package-lock.json' -g 'npm-shrinkwrap.json' \
  -g 'pnpm-lock.yaml' -g 'yarn.lock' -g 'requirements*.txt' \
  -g 'pyproject.toml' -g 'uv.lock' -g '!**/node_modules/**' -g '!**/.venv/**' \
  "$WORKSPACE_ROOT" || true
```

```bash
# Identify files that appear to contain registry credentials without printing their contents.
rg --files-with-matches --hidden -i '(_authToken|NPM_TOKEN|NODE_AUTH_TOKEN|PYPI_TOKEN|TWINE_PASSWORD|npm_[A-Za-z0-9]{20,}|pypi-[A-Za-z0-9]{20,})' \
  -g '.npmrc' -g '.pypirc' -g 'package.json' -g 'pyproject.toml' \
  -g '.github/workflows/*.yml' -g '.github/workflows/*.yaml' \
  -g '!**/.git/**' -g '!**/node_modules/**' "$WORKSPACE_ROOT" || true
```

```bash
# Review workflows for compromised actions, risky triggers, broad permissions, OIDC minting, and untrusted event context.
rg -n '(codfish/semantic-release-action|simonecorsi/mawesome|pull_request_target|workflow_run|issue_comment|repository_dispatch|allow-unsafe-pr-checkout|id-token:[[:space:]]*write|permissions:[[:space:]]*write-all|secrets:[[:space:]]*inherit|github\.event\..*(title|body|head_ref|ref|label|message|name))' \
  -g '.github/workflows/*.yml' -g '.github/workflows/*.yaml' "$WORKSPACE_ROOT" || true
```

```bash
# Find third-party actions that are not pinned to a full 40-character commit SHA.
rg -n 'uses:[[:space:]]*[^[:space:]]+/[^[:space:]@]+@[^#[:space:]]+' \
  -g '.github/workflows/*.yml' -g '.github/workflows/*.yaml' "$WORKSPACE_ROOT" \
  | rg -v '@[0-9a-f]{40}([[:space:]#]|$)' || true
```

```bash
# Surface MCP, agent, editor, task, extension, and devcontainer configuration for manual review.
find "$WORKSPACE_ROOT" -type f \( \
  -name 'mcp.json' -o -name 'mcp.yaml' -o -name 'mcp.toml' -o \
  -name 'AGENTS.md' -o -path '*/.claude/settings.json' -o \
  -path '*/.vscode/extensions.json' -o -path '*/.vscode/settings.json' -o \
  -path '*/.vscode/tasks.json' -o -path '*/.cursor/rules/*' -o \
  -path '*/.github/copilot-instructions.md' -o -name 'devcontainer.json' \
\) -print
```

```bash
# After a suspicious install, import, extension activation, or agent run, list long-running interpreters by executable name only.
ps -axo pid,ppid,etime,comm | rg '(node|bun|python|python3|java|ruby|sh|bash)$' || true
```

```bash
# - Rebuild affected runners and developer environments from clean images.
```

```bash
# - Open unfamiliar repositories in restricted or untrusted mode first.
```
