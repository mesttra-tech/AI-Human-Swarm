Mode: Public defensive guidance. No private environment data included.

## Executive Summary

- CISA KEV remains at catalog version 2026.07.07 as of research time on 2026-07-09. The four July 7 additions, Adobe ColdFusion CVE-2026-48282, Langflow CVE-2026-55255, Joomlack Page Builder CVE-2026-56290, and JoomShaper SP Page Builder CVE-2026-48908, are due tomorrow, 2026-07-10.
- GitHub Advisory Database returned 22 npm malware advisories published from 2026-07-08T00:00:00Z through research time, including AI/dev-tool-looking package names. Advisory publication time is not proof of local installation, but it is enough to trigger manifest, lockfile, registry, cache, and endpoint reconciliation.
- npm v12 is now tagged latest and turns install-time security defaults on: lifecycle scripts, implicit native builds, git dependencies, and remote URL dependencies are opt-in. Treat any broad re-enable as a code-reviewed security decision.
- GitHub Actions runner and OIDC dates are now close: Enterprise Cloud with Data Residency has brownouts on 2026-07-13, 2026-07-15, and 2026-07-17; immutable OIDC subject claims become automatic for new repositories and renames on 2026-07-15; safer `pull_request_target` checkout enforcement backports on 2026-07-16 for floating supported major tags.
- AI agents, MCP servers, editor extensions, workspace trust, package install hooks, and CI/CD workflows are the same control surface in practice: untrusted instructions or metadata can become privileged execution. Pin reviewed inputs, minimize permissions, record provenance, and require deterministic approval outside the model context for consequential actions.

## Copy/Paste Assessment

Run only checks that match an environment you are authorized to review. These commands list filenames, package references, workflow settings, or process names; they are not intended to print secret values.

```bash
# Set this to the workspace you are authorized to review.
export WORKSPACE_ROOT="<WORKSPACE_ROOT>"
cd "$WORKSPACE_ROOT"
```

```bash
# Pull current CISA KEV data for defensive prioritization.
curl -fsSL https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json -o kev.json
jq -r '.catalogVersion, .dateReleased, (.vulnerabilities | sort_by(.dateAdded) | reverse | .[0:20][] | [.dateAdded,.dueDate,.cveID,.vendorProject,.product] | @tsv)' kev.json
```

```bash
# Find manifests, lockfiles, registry configs, native-build metadata, and Python startup hooks.
find "$WORKSPACE_ROOT" -type f \( \
  -name package.json -o -name package-lock.json -o -name npm-shrinkwrap.json -o \
  -name pnpm-lock.yaml -o -name yarn.lock -o -name bun.lock -o \
  -name requirements.txt -o -name pyproject.toml -o -name pylock.toml -o -name uv.lock -o \
  -name binding.gyp -o -name '*.pth' -o -name .npmrc -o -name .pypirc \
\) -not -path '*/node_modules/*' -not -path '*/.venv/*' -print
```

```bash
# Reconcile the July 8-9 npm malware advisory names against manifests and lockfiles.
rg -n '(@calm2026/imux|@vite-ln/build-ts|calvuepro|clavuepro|clavue-agent-sdk|clavue|myclaude-code|tailwind-core|common-tg-service|promo-helper|ams-ssk|mci-sdk|karem-dp|na-rony-test-karem|na-rony-test|nam-os-a-man|rony-testing|na-rony|vite-json-pwa|gas-log|nodemon-node|ts-await)' \
  -g 'package.json' -g 'package-lock.json' -g 'npm-shrinkwrap.json' \
  -g 'pnpm-lock.yaml' -g 'yarn.lock' -g 'bun.lock' \
  -g '!**/node_modules/**' "$WORKSPACE_ROOT" || true
```

```bash
# Review declared Node lifecycle scripts and npm v12 install exceptions without executing them.
rg -n '"(preinstall|install|postinstall|prepare)"[[:space:]]*:' \
  -g 'package.json' -g '!**/node_modules/**' "$WORKSPACE_ROOT" || true
rg -n '(allowScripts|allow-scripts|allow-git|allow-remote|approve-scripts|trustedPublisher|trusted-publisher)' \
  -g 'package.json' -g '.npmrc' -g 'npm-shrinkwrap.json' -g '!**/node_modules/**' "$WORKSPACE_ROOT" || true
```

```bash
# Identify files that appear to contain registry or automation credential references without printing values.
rg --files-with-matches --hidden -i '(_authToken|NPM_TOKEN|NODE_AUTH_TOKEN|PYPI_TOKEN|TWINE_PASSWORD|GITHUB_TOKEN|ACTIONS_ID_TOKEN_REQUEST_TOKEN)' \
  -g '.npmrc' -g '.pypirc' -g 'package.json' -g 'pyproject.toml' \
  -g '.github/workflows/*.yml' -g '.github/workflows/*.yaml' \
  -g '!**/.git/**' -g '!**/node_modules/**' "$WORKSPACE_ROOT" || true
```

```bash
# Review workflow trust boundaries, caches, OIDC, broad permissions, and unsafe interpolation surfaces.
rg -n '(pull_request_target|workflow_run|issue_comment|repository_dispatch|actions/cache|id-token:[[:space:]]*write|permissions:[[:space:]]*write-all|secrets:[[:space:]]*inherit|allow-unsafe-pr-checkout|github\.event\..*(title|body|head_ref|ref|label|message|name))' \
  -g '.github/workflows/*.yml' -g '.github/workflows/*.yaml' "$WORKSPACE_ROOT" || true
```

```bash
# Find third-party Actions that are not pinned to a full 40-character commit SHA.
rg -n 'uses:[[:space:]]*[^[:space:]]+/[^[:space:]@]+@[^#[:space:]]+' \
  -g '.github/workflows/*.yml' -g '.github/workflows/*.yaml' "$WORKSPACE_ROOT" \
  | rg -v '@[0-9a-f]{40}([[:space:]#]|$)' || true
```

```bash
# Review Java CI supply-chain controls where setup-java is used.
rg -n '(actions/setup-java@|verify-signature|verify-signature-public-key|cache:[[:space:]]*maven|MAVEN_ARGS)' \
  -g '.github/workflows/*.yml' -g '.github/workflows/*.yaml' "$WORKSPACE_ROOT" || true
```

```bash
# Surface agent, MCP, editor, plugin, task, hook, memory, and devcontainer configuration.
find "$WORKSPACE_ROOT" -type f \( \
  -name 'mcp.json' -o -name 'mcp.yaml' -o -name 'mcp.toml' -o \
  -name 'AGENTS.md' -o -path '*/.claude/settings.json' -o \
  -path '*/.vscode/extensions.json' -o -path '*/.vscode/settings.json' -o \
  -path '*/.vscode/tasks.json' -o -path '*/.cursor/rules/*' -o \
  -path '*/.github/copilot-instructions.md' -o -name 'managed-settings.json' -o \
  -name 'devcontainer.json' \
\) -print
```

```bash
# After a suspicious install, import, extension activation, or agent run, list long-running interpreters by executable name only.
ps -axo pid,ppid,etime,comm | rg '(node|bun|python|python3|java|ruby|sh|bash)$' || true
```

- The 2026-07-13, 2026-07-15, and 2026-07-17 runner brownouts apply to GitHub Enterprise Cloud with Data Residency. Standard GitHub Enterprise Cloud has a later schedule, and GitHub Enterprise Server is not currently affected by that enforcement.
- GitHub's immutable OIDC subject change applies automatically to new repositories and repository renames after 2026-07-15; existing repositories require explicit opt-in.
- GitHub's safer `pull_request_target` checkout behavior does not block every possible privileged untrusted checkout or execution path. Shell, git, and CLI steps still need review.
- GitHub malware-advisory publication dates do not by themselves establish when a package was uploaded, installed, or executed. Local exposure requires manifest, lockfile, registry, cache, artifact, and install-timeline evidence.
- Red Hat states its affected packages were not part of released Red Hat products or managed cloud services and that no customer action is required. The incident remains a general developer-tooling lesson, not a blanket Red Hat exposure claim.
